# Notebooks for the iron-fuel coating proposal

- `NB_Carriers.ipynb`: energy per kilogram and per liter of fuels and carriers, with every value and its source.
- `NB_Econ.ipynb`: emissions attributable to the charging electricity of the iron loop (electricity only), and the coating break-even.
- `NB_Bounds.ipynb`: particle dose, detection limit, and heat-transfer screens for a thin coating.

Each notebook is self-contained and runs top to bottom. Scenario inputs are labeled as assumptions in the code.
